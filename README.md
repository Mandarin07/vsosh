# malware-analys-vsosh
Project for VSOSH Olympiad. Checking for malware activity in files via Raspberry Pi 5 as a Sandbox platform. Full connect to Telegram

## Installation

Use the package manager two main scripts
- `harden.sh` 
- `install.sh`
to harden your Raspberry For project and install to install all components and dependences

## Changing config.yaml

in `~/config/config.yaml` change settings to yours

## Starting up the bot
to start up the Telegram bot use 
```bash
source venv/bin/activate
pip3 install -r requirements.txt
python3 ~/tgbot.py
```
